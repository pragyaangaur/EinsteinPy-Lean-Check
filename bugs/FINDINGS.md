# Findings

This file lists the 33 bug records in this directory, generated by `scripts/findings.py`. Every record is a property that was refuted on the Lean model, or a physics check that failed, and was then confirmed on einsteinpy at commit `63e1c54`. Each one has a reproducer in `repro/` that prints `REPRODUCED`, and `scripts/check_bugs.py` reruns all of them.

By severity there are 4 high, 11 medium and 18 low records. By area the counts are Coordinates 6, Curvature 2, Geodesic 6, Helpers 1, Metric 4, Predefined 6, Tensor 3, Utils 5.

None of these has been reported to einsteinpy by this project. On 24 and 25 November 2026 every record was searched for in the open and closed issues and pull requests of einsteinpy/einsteinpy. NEW means no issue or pull request describes the bug. RELATED means a report shares the cause or the code but does not describe this bug. KNOWN-OPEN and KNOWN-CLOSED mean an open or closed issue or pull request covers it. A search that finds nothing does not prove that nobody has reported it.

By verdict there are NEW 24, RELATED 3, KNOWN-OPEN 4, KNOWN-CLOSED 2.
